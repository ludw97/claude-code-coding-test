# 新华医院2026年5月运营分析 — 第五部分：重点关注事项及建议（更新版）

> 基于PPT前四部分（收支结余、业务量分析、收入分析、均次费用分析）及成本分析、预算执行部分的经济运行数据，梳理5月重点关注事项及应对建议。标注了问题与4月相比的变化趋势。

---

## 一、奉贤院区持续亏损，杨浦院区住院规模萎缩，部分科室业务下滑明显

### 数据分析（5月）

**收支方面：**
- 5月全院收支结余3,259万元，其中杨浦院区4,736万元，**奉贤院区-1,477万元**（单月亏损）
- 1-5月累计收支结余-17,848万元，其中奉贤院区-16,877万元，占全院亏损的94.6%

**杨浦院区业务萎缩：**
- 杨浦院区住院人次同比**下降8.3%**（1.19万 vs 1.30万），住院收入同比**下降2.2%**（3.02亿 vs 3.09亿）
- 杨浦院区门诊同比下降科室：中医(-15.02%)、耳鼻咽喉(-4.65%)、疼痛(-3.71%)、乳腺外科(-2.78%)
- 杨浦院区儿科门诊同比下降：儿呼吸(-37.93%)、儿急危(-27.24%)、儿神外(-22.31%)、新生儿(-21.75%)、儿普外(-15.88%)
- 杨浦院区住院同比下降前十：**肛肠(-58.90%)、乳腺(-45.58%)、五官(-33.18%)、骨科(-33.01%)、泌尿外(-28.88%)**、急诊医学(-28.48%)、儿泌尿(-19.19%)、儿急危(-18.75%)、儿骨科(-18.07%)、移植科(-13.79%)

**手术能力提升偏慢：**
- 住院手术781人次，同比仅增5.5%；四级手术216人次，同比仅增1.9%；微创手术265人次，同比增12.3%
- 四级手术增速远低于整体手术增速，高难度手术能力有待提升

**儿科结构性分化：**
- 儿消化科门急诊和住院两项业务量**同时负增长**
- 儿内分泌、儿骨、儿泌尿门急诊增长但住院下降
- 儿神外、儿呼吸、儿普外住院增长但门急诊下降

### 判断

> 🔴 该问题**本月持续存在且部分指标恶化**。奉贤院区5月单月亏损（-1,477万元）较1-5月月均亏损（-3,375万元）有所收窄，但仍是全院亏损的主要来源。杨浦院区住院人次和住院收入降幅较上月进一步扩大（住院人次从约-5.8%扩大至-8.3%），呈现加速萎缩趋势。四级手术增速（仅1.9%）远低于整体手术增速（5.5%），反映高附加值手术占比下降。

### 建议

1. **奉贤院区**：加快奉贤院区门诊和住院业务导入，重点推动成人手术科室在奉贤开设门诊和日间手术；评估奉贤院区人员配置效率，奉贤人员经费占该院区成本36.7%，高于全院34.1%的水平
2. **杨浦院区住院**：针对住院同比下降幅度最大的科室（肛肠-58.9%、乳腺-45.58%、五官-33.18%、骨科-33.01%），由医务部逐科分析原因；关注是否因奉贤分流导致，制定针对性改善措施
3. **四级手术**：分析四级手术增幅偏低的原因，是否存在高难度手术外流或手术结构向低级别偏移的趋势
4. **儿科**：重点关注业务量同时下滑的儿消化科，以及门急诊与住院背离的科室，制定专项提升方案

## 二、收入结构持续失衡，药耗占比远超年度目标，奉贤院区结构性问题突出

### 数据分析（5月）

**药耗占比（1-5月累计）：**
- 实际值**53.20%**，高于年度目标（49%）**4.2个百分点**（问题持续）
- 5月当月药占比同比下降2.2个百分点（改善），但耗占比同比**上升1.6个百分点**（恶化），两相抵消后结构改善不明显

**耗材收支管理：**
- 卫生材料成本收入比1.21（与目标持平，但为1-5月累计值；5月单月为1.16，有所改善）
- **可收费耗材成本收入比0.92**，即成本与收入差额达**1,341万元**（5月单月），收支差异过大
- 可收费耗材成本收入比从1月的1.29逐月下降至5月的0.92，趋势向好但仍需关注

**奉贤院区结构严重失衡：**
- 奉贤院区耗占比达**38%**，远高于杨浦院区
- 奉贤院区劳务占比仅**21.5%**（杨浦约25.9%），收入"含金量"低
- 奉贤院区医疗收入1.43亿元，占全院22.5%，但成本1.57亿元，**医疗服务盈余-1,444万元**

**检验试剂：**
- 试剂成本与检验项目收入占比**36.19%**，高于目标（30%）**6.19个百分点**
- 5月检验试剂成本收入比重80.2%，同比上升0.6个百分点

**药耗占比超50%的高风险科室（5月当月）：**

|------|------|----------|
| 成人手术 | 介入血管外科 | 85.1% |
| 成人手术 | 神经外科 | 73.4% |
| 成人手术 | 骨科 | 66.1% |
| 成人手术 | 脊柱中心 | 65.1% |
| 成人手术 | 疼痛科 | 62.9% |
| 成人手术 | 心胸外科 | 62.2% |
| 成人手术 | 肛肠外科 | 52.3% |
| 成人非手术 | 肿瘤内科 | 76.9% |
| 成人非手术 | 血液内科 | 75.9% |
| 成人非手术 | 心血管内科 | 74.3% |
| 成人非手术 | 神经内科 | 56.6% |
| 成人非手术 | 中医科 | 54.6% |
| 儿童 | 儿神经外科 | 66.7% |
| 儿童 | 儿骨科 | 60.8% |
| 儿童 | 儿神经内科 | 50.7% |
| 儿童 | 儿血液肿瘤科 | 54.9% |

### 判断

> 🔴 该问题**本月持续存在**。药耗占比53.20%离49%目标仍有较大差距，且5月耗占比环比上升。奉贤院区收入结构失衡（耗占比38% vs 劳务占比21.5%）是结构性问题，根本原因在于奉贤院区以手术和检查检验为主，缺乏高附加值劳务服务。

### 建议

1. **药耗占比管控**：对药耗占比超50%的科室实施月度监测预警，逐科设定药耗占比下降目标；重点关注5月耗占比同比上升的科室（心血管+0.97pp、介入+2.39pp、神经内+6.14pp等）
2. **可收费耗材收支差异**：1,341万元的收支差额需由资产管理部逐品类核查，是否存在多领少收、计价错误等问题
3. **奉贤院区收入结构**：推动在奉贤院区增设专家门诊和特需门诊（目前奉贤专家门诊2.49万人次占该院区门诊的26.2%），提升劳务收入占比
4. **检验试剂**：成本收入比80.2%接近盈亏临界点，需评估检验项目定价与实际成本的匹配度

## 三、预算执行"收入缓、成本快"剪刀差持续，专项收入缺口大

### 数据分析（5月）

**收支预算执行：**
- 医疗收入预算执行率**40.6%**，低于时间节点（41.7%）**1.1个百分点**（较上月偏离度-1.2%收窄0.1pp，边际改善）
- 医疗成本预算执行率**44.0%**，高于时间节点（41.7%）**2.3个百分点**（较上月偏离度+2.6%收窄0.3pp）
- 工资总额预算执行率45.2%，高于时间节点3.5个百分点（扣除年终奖因素后40.6%，低于时间节点1.1pp）

**成本指标全面超目标（1-5月）：**
- 万元医疗收入能耗成本223元，超目标36元（目标187元）
- 万元医疗收入维修成本346元，超目标39元（目标307元）
- 万元医疗收入物业成本374元，超目标17元（目标357元）
- 能耗成本1-5月累计3,200万元，同比增17.3%（全年目标较25年减少1,000万元）

**专项收入执行严重滞后：**

| 指标 | 执行率 | 与时间节点偏差 |
|------|--------|----------------|
| 互联网医疗收入 | 33.1% | -8.6% |
| 体检中心收入 | 18.8% | -22.9% |
| 镜朗住院收入 | 31.2% | -10.5% |
| 合作共建及外部捐赠 | 15.2% | -26.5% |
| 学习班收入 | 16.2% | -25.5% |
| 投资收益 | 18.2% | -23.5% |
| 成果转化收入 | 0% | -41.7% |

### 判断

> 🟡 该问题**本月持续存在但边际改善**。收入预算偏离度从-1.2%收窄至-1.1%，成本预算偏离度从+2.6%收窄至+2.3%。但专项收入（互联网、体检、镜朗、合作共建、成果转化）执行率普遍不足35%，是收入预算完成的最大拖累项。成本端三项万元收入指标均超标，"收入缓、成本快"的矛盾尚未扭转。

### 建议

1. **成本管控**：综合保障部需制定能耗、维修、物业三项成本的月度压降计划；1-5月能耗已达3,200万元（全年目标较25年减少1,000万元），需评估目标可达性
2. **专项收入攻坚**：
   - 体检中心收入执行率仅18.8%（偏差-22.9%），需尽快推动团体体检签约和个检引流
   - 互联网医疗收入（33.1%）需加大线上问诊推广力度
   - 合作共建及外部捐赠（15.2%）需由院长办公室制定下半年专项推进方案
   - 成果转化收入至今为0，科研部需梳理现有可转化成果
3. **预算动态调整**：建议在半年度节点对预算目标进行中期评估，对明显无法达成的专项收入目标（如成果转化300万元）进行合理调整，避免年底大幅偏离

## 四、卫生材料管理存在库存与结算风险，发票未达金额高企 🆕

### 数据分析（5月，新增问题）

**发票未达问题：**
- 截至5月31日，物资已入库发票未达金额**8,979.02万元**，其中高值耗材5,407.93万元，低值耗材3,571.1万元
- 建发发票未达合计5,926.4万元（含已开具未审核的红字发票470.8万元）
- 国药满意（试剂耗材供应商）5月新增未达2,908.49万元
- 原文指出：**"资产管理部未及时将发票提交并审核后推送至财务审核，导致账面显示发票未达"**

**麻醉重症耗材异常增长：**
- 麻醉与重症医学科5月耗材862.36万元，同比激增**1049.93%**（去年5月仅74.99万元）
- 其中麻醉科（麻醉）711.30万元，同比3913.88%
- 环比4月（1,075.03万元）虽有下降19.78%，但绝对金额仍处高位

**耗材成本收入比（5月当月，环比恶化科室）：**
- 泌尿外科成本收入比从0.94升至1.16（环比+0.22）
- 眼科从0.68升至0.92（环比+0.24）
- 妇产科从0.66升至1.06（环比+0.40，已亏损）

### 判断

> 🔴 这是一个**新发现的重大内控问题**。发票未达近9,000万元，反映出物资入库与财务结算之间存在严重的流程脱节。按照"当月消耗、当月结算"的管理要求，5月末仍有近9,000万元发票未达，不仅影响财务数据的真实性（成本可能被低估），更存在供应商纠纷和审计风险。麻醉重症耗材的千倍级增长也需要核查其合理性。

### 建议

1. **发票未达清理**：由资产管理部牵头，在6月底前完成8,979.02万元发票未达的清理入账工作；对建发5,926.4万元未达发票（含红字470.8万元）进行逐笔核实
2. **流程整改**：建立"入库即推送、当月必审核"的刚性流程，将发票提交及时率纳入资产管理部绩效考核
3. **麻醉重症耗材核查**：由医务部和资产管理部联合核查麻醉科耗材使用量同比激增39倍的原因，是否存在不合理使用、套计或多计
4. **耗材成本收入比超1科室预警**：对泌尿外科(1.16)、妇产科(1.06)、疼痛科(1.03)、肾脏风湿(2.11)等成本收入比超1的科室实施耗材领用限额管理

## 五、物业管理费与委托业务费大幅增长，需关注外包服务性价比 🆕

### 数据分析（5月，问题升级）

**物业管理费（5月当月）：**
- 支出1,182万元，同比增幅**62.3%**（增长453万元）
- 其中：运送服务费212万元（+171.8%）、保安管理费197万元（+35.9%）、保洁服务费481万元（+33.2%）、物业其他292万元（+101.4%）
- 物业其他增长含：电梯驾驶服务费+58万元、院区物业管理费+21万元、垃圾清运费+18万元、医废处置费+16万元、被服洗涤费+15万元、会务服务费+15万元
- 杨浦院区按后勤合同计提额增加90万元

**委托业务费（5月当月）：**
- 支出240万元，同比增幅**355.9%**（增长187万元）
- 其中外送检测费增长111万元，科研配套经费使用增长76万元

**万元医疗收入物业成本**374元（目标357元，超17元）

### 判断

> 🟡 这是一个**持续恶化的问题**。物业费增幅62.3%远超业务量增幅（34%）和收入增幅（32.3%），说明存在明显的规模不经济。奉贤院区新增物业成本（388万元/月）是主要驱动力，但需评估外包服务与自营的成本效益对比。委托业务费增长355.9%主要来自外送检测量增加，需关注外送检测的必要性和定价合理性。

### 建议

1. **物业合同审计**：对杨浦和奉贤两院区全部物业服务合同进行成本效益评估，重点核查运送服务费（+171.8%）和物业其他（+101.4%）的增长合理性
2. **外包vs自营评估**：对电梯驾驶（+58万元）、被服洗涤（+15万元）等单项服务开展自营与外包的成本对比分析
3. **外送检测管控**：委托业务费中外送检测费增长111万元，医务部需评估外送检测项目的必要性，是否有条件收回院内检测
4. **奉贤院区物业独立核算**：将奉贤院区388万元物业费单独建立台账，对标同体量院区的物业费水平

## 六、投资收益大幅下滑，非医疗收入来源堪忧 🆕

### 数据分析（5月）

- 新华医疗开发公司5月投资收益仅**82.36万元**，同比**减少220.70万元**，降幅**72.82%**
- 1-5月累计投资收益910万元，执行率仅18.2%，偏差-23.5个百分点

### 判断

> 🟡 这是一个**持续恶化的问题**。投资收益大幅下滑进一步加剧了医院收支平衡压力。当前主要依赖医疗收入弥补亏损，但医疗收入增长受到业务量天花板的限制。

### 建议

1. 由院办牵头，对新华医疗开发公司经营状况进行全面评估，明确投资收益下滑的具体原因
2. 探索多元化收入来源（如成果转化、技术输出、培训服务等），减少对单一产业公司投资收益的依赖
3. 将投资收益指标纳入产业公司年度考核，确保全年5,000万元目标的达成
