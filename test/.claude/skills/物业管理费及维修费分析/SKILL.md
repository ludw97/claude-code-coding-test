# 物业管理费及维修费分析

根据新华医院物业及维修明细账 Excel 文件，按运营成本分类汇总物业管理费，
按科目名称和运营成本两级分类汇总维修费，自动更新分析底稿中相关 sheet 的数据。

## 输入

- **本年明细文件**：如 `202604物业及维修.xlsx`（.xlsx 新格式或 .xls 旧格式）
- **上年同期明细文件**：如 `202504物业及维修.xls`（.xls 旧格式）
- **分析底稿**：如 `4月分析底稿.xlsx`
- **物业及维修明细文件**（两个独立 Excel，每月一份）

## 执行

```bash
python .claude/skills/物业管理费及维修费分析/scripts/property_analysis.py \
  <本年明细文件> <上年同期明细文件> <分析底稿> [--output OUTPUT] [--mode MODE]
```

**模式选项**:
- `--mode all`（默认）：同时更新物业管理费和维修费
- `--mode property`：仅更新物业管理费
- `--mode maintenance`：仅更新维修费

示例：
```bash
# 完整分析
python .claude/skills/物业管理费及维修费分析/scripts/property_analysis.py \
  202604物业及维修.xlsx 202504物业及维修.xls 4月分析底稿.xlsx

# 仅维修费
python .claude/skills/物业管理费及维修费分析/scripts/property_analysis.py \
  202604物业及维修.xlsx 202504物业及维修.xls 4月分析底稿.xlsx --mode maintenance
```

无 `--output` 参数时，输出文件自动命名为 `<原名>_updated_<MMDD>.xlsx`。

## 维修费分析

### 数据规则

维修费与物业管理费共用同一明细文件，通过科目编码识别维修费行：
- **2026新格式**：科目编码含 `0412`（如 `5001041201`、`5101041204`）
- **2025旧格式**：科目代码去点后含 `0412`（如 `5001.04.12.01`）

| 文件格式 | 科目编码列 | 科目名称列 | 运营成本列 | 院区列 | 借方金额列 |
|----------|-----------|-----------|-----------|--------|-----------|
| 2026新格式 | col 4 (D) | col 5 (E) | col 7 (G) | col 8 (H) | col 11 (K) |
| 2025旧格式 | col 1 (A) | col 2 (B) | col 12 (L) | col 9 (I) | col 13 (M) |

### 两级分类体系

#### 一级分类（→ 维修护费 sheet）

基于**科目名称**，按优先级匹配：

| 匹配关键词 | 分类标签 | 维修护费行 |
|-----------|---------|-----------|
| 设备日常维修 | 设备维修 | R5 |
| 网络信息系统运行与维护费 | 网络维修 | R4 |
| 房屋日常维修 | 房屋维修 | R7 |
| 其他 + 科目编码以04结尾 | 后勤维修 | R6 |

- **2026新格式**：科目名称如 `设备日常维修（护）费`、`网络信息系统运行与维护费`、`房屋日常维修（护）费`、`其他`
- **2025旧格式**：科目名称如 `业务活动费用_商品和服务费用_维修（护）费_设备日常维修（护）费`

#### 二级分类（→ 后勤维修 sheet）

仅对"后勤维修"行，基于**运营成本**（2025格式先剥离 `运营成本:维修维护_` 前缀）：

| 匹配关键词 | 分类标签 | 左表行 | 右表行 |
|-----------|---------|-------|-------|
| 物业维修服务费 | 物业维修 | R6 | R6 |
| 电梯运行管理费 | 电梯运行 | R7 | - |
| 通用设施设备管理 | 通用设施 | R8 | R7 |
| 空调运行管理费 | 空调运行管理费 | R9 | R8 |
| 电站运行管理费 | 电站运行 | R10 | - |
| 给排水锅炉运行管理费 | 给排水锅炉 | R11 | - |
| 后勤智能化平台 | 后勤智能化 | R12 | - |
| 污水处理站运行管理费 | 污水处理站 | R13 | - |
| 污水管线养护费 | 污水管线 | R14 | - |
| 医用气体运行管理费 | 医用气体 | R15 | - |
| 其他 | 其他 | - | - |

> 右表仅包含物业维修、通用设施设备管理、空调运行管理费 3 个显式子项。
> 右表 R9"其他"为公式 `=L5-L6-L7-L8`。

### 更新范围

#### 维修护费 sheet

仅更新**硬编码数值单元格**（行 4-7 的 C/D/E 列），保留所有公式：
- C 列：当月合计（万元）
- D 列：奉贤院区（万元）
- E 列：上年同期（万元）
- F/G 列：增减额/增减率（公式，自动重算）
- R3（维修费合计）：公式 `=商品服务!C6`
- R5 柯渡数据（H5/I5/J5）：不更新，保留原值

#### 后勤维修 sheet

仅更新**硬编码数值单元格**，保留所有公式：

- **左表 (C-J列)**：
  - 更新 R6-R15 中 D/E/F 列数值（当月合计/奉贤院区/上年同期）
  - 保留 G/H 列公式
  - 保留 R5 公式（`=维修护费!C6`）
  - 保留 R16 公式（`=D5-D6-D7-...-D15`，其他）

- **右表 (K-P列)**：
  - 更新 R6-R8 中 L/M/N 列数值
  - 保留 O/P 列公式
  - 保留 R9 公式（`=L5-L6-L7-L8`，其他）

#### 商品服务 sheet R6

更新维修费汇总行：
- C6 ← 本年维修费总计（万元）
- D6 ← 本年奉贤院区维修费合计（万元）
- E6 ← 上年维修费总计（万元）

### 排除的科目

非维修费科目（科目编码不含 `0412`）的"其他"科目名称行不会被纳入维修费分析。
物业管理费行（科目编码含 `0409`）由物业管理费分析模块独立处理。

## 验证

运行后检查输出摘要：

### 物业管理费
- 每个分类的汇总金额（元）和院区分布
- 物业管理费合计金额（万元）
- `updated_cells`：成功更新的单元格数

### 维修费
- 一级分类（设备/网络/房屋/后勤维修）的汇总金额和院区分布
- 二级分类（后勤维修 10 个子项）的汇总金额和院区分布
- **交叉验证**：后勤维修子项之和 = 一级后勤维修值（预期完全相等）
- 维修费合计（万元）

### 交叉验证
- 左表子项之和 ≈ R5 物业管理费汇总
- 奉贤院区子项之和 ≈ 奉贤物业管理费
- 上年数据仅来自杨浦院区
- 后勤维修子项之和 = 维修护费 R6 后勤维修值
- F/G 列公式保留且数值正确

## 扩展

### 物业管理费
如需增加新的分类或调整映射：
1. 编辑 `references/category_mapping.json` 的 `categories` 数组
2. 添加 `keywords` 和 `label`
3. 指定 `left_row`（左表行号）和/或 `right_row`（右表行号）
4. 如需排除新的非物业管理分类，添加到 `exclude_keywords`

### 维修费
如需调整维修费分类：
1. 编辑 `references/category_mapping.json` 的 `maintenance` 段
2. 调整 `top_level.categories` 或 `logistics_repair.left_block.sub_categories`
3. 添加新的 keywords/label/data_key 组合
4. 重新运行脚本测试
