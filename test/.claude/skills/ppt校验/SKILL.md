# PPT 校验技能

对新华医院月度运营分析 PPT 报告进行全量数据一致性校验，检测表格、文字描述、图表三者之间的数据矛盾。

## 校验范围

| 校验类型 | 说明 |
|----------|------|
| **文字 vs 表格** | 同一页内文字描述中的数值是否与表格中对应指标一致 |
| **图表 vs 表格** | 图表（柱状图/折线图/饼图等）数据是否与表格对应行列一致 |
| **图表 vs 文字** | 图表数据是否与同一页文字描述中的对应数值一致 |

## 执行

```bash
python .claude/skills/ppt校验/scripts/ppt_verify.py <pptx文件路径> [--tol 0.005]
```

示例：
```bash
python .claude/skills/ppt校验/scripts/ppt_verify.py 新华医院2026年5月运营分析_updated_0604.pptx
```

- `--tol`：容忍度（默认 0.5%），超过此比例的差异视为不一致
- 输出报告自动保存到 PPT 同目录下的 `ppt全量校验结果.txt`

## 核心能力

### 单位归一化

自动识别并统一中文财务单位：

| 单位 | 换算 |
|------|------|
| 亿元 | × 100,000,000 |
| 万元 | × 10,000 |
| 千元 | × 1,000 |
| 元 | × 1 |
| 万人次 | × 10,000 |
| % | × 0.01 |
| 个百分点 | × 0.01 |

因此 `1100万` 和 `0.11亿` 会被正确识别为一致。

### 图表数据提取

使用 XML 级别解析，支持 python-pptx 原生不支持的类型：
- 柱状图 (barChart, COLUMN_CLUSTERED, COLUMN_STACKED)
- 折线图 (lineChart)
- 散点图 (scatterChart, XY_SCATTER)
- 饼图 (pieChart, pie3DChart)
- 组合图 (barChart + lineChart 混合)

图表校验逻辑：
- 图表 **系列名**（如 "2026年5月"）→ 匹配表格 **列标题**
- 图表 **类别名**（如 "专科门诊"）→ 匹配表格 **行标签**
- 饼图自动识别比率值（<1），避免与绝对数误比较

### 文字数值提取

从文本段落中提取数值时：
- 根据前置关键词（"为""达""是"等）和数值周围的上下文推断指标名称
- 区分绝对数、百分比、增减额等数值类型
- 过滤日期数字、序号等非指标数值
- 过滤"其中"子项（表格通常不含子项拆解）

### 智能列匹配

文字与表格匹配时，自动识别列类型（绝对值列/百分比列/增减列），避免：
- 百分比文字匹配到绝对数列
- 增减额文字匹配到基数列
- 成本收入率匹配到增减率列而非基数值列

## 校验逻辑说明

### 匹配策略

| 场景 | 行标签匹配 | 列标题匹配 | 权重 |
|------|-----------|-----------|------|
| 文字 vs 表格 | `sim()` 标签相似度 ≥ 0.80 | 根据数值类型自动选列 | 标签为主 |
| 图表 vs 表格 | `sim()` 类别→行匹配 | `sim_col()` 系列→列匹配 | 行 70%/列 30% |
| 图表 vs 文字 | `sim()` 类别→标签匹配 | 系列名（年份）辅助匹配 | 类别为主 |

### 相似度函数

- **`sim()`**：标签相似度，剔除日期前缀、序号、"其中"等干扰后使用 `SequenceMatcher`
- **`sim_col()`**：列标题相似度，**不剔除日期**（否则 "2025年5月" 和 "2026年5月" 都被归一化为 "5月" 而不可区分）

### 已知限制

1. **饼图比率值**：饼图的比率数据无法与表格绝对值直接比较（缺少总量），跳过此类比较
2. **跨页一致性**：暂不校验同一指标在不同页面数值是否一致（后续可扩展）
3. **图表数据标签**：仅提取图表系列数据（cat/val），不提取图表上的独立数据标签文字
4. **列单位推断**：表格无显式单位标注时，通过数值范围和列标题关键词推断（可能偶有偏差）

## 注意事项

- 脚本仅读取 PPT，**不会修改原文件**
- 6 个文字 vs 表格问题通常为误报（时间口径不匹配、列匹配偏差等），需人工复核
- 图表 vs 表格 和 图表 vs 文字 出现问题时通常值得关注
- 如报告中所有图表校验结果均为 0 个问题，说明数据一致性良好
